# 05 — Quick Reference

## Naming Conventions

| Thing | Convention | Example |
|---|---|---|
| Go files | snake_case | `expense_service.go` |
| Go types | PascalCase | `ExpenseService` |
| Go exported functions | PascalCase | `CreateExpense` |
| Go unexported functions | camelCase | `validateSplits` |
| DB tables | snake_case plural | `expense_categories` |
| DB columns | snake_case | `allocation_amount` |
| GraphQL types | PascalCase | `ExpenseCategory` |
| GraphQL fields | camelCase | `allocationAmount` |
| GraphQL monetary fields | String (not Float) | `"350.00"` |
| sqlc query names | PascalCase verb-noun | `GetCategoriesForBudget` |
| Sentinel errors | ErrPascalCase | `ErrSplitMismatch` |
| DataLoaders | PascalCase + Loader | `CategorySpentLoader` |
| Service types | PascalCase + Service | `BudgetService` |
| Middleware context keys | unexported type | `type contextKey string` |

## Atlas Commands

```bash
# Preview what will change (dry run)
atlas schema diff \
  --from "postgres://localhost/budget_dev" \
  --to   "file://db/schema.hcl"

# Generate versioned migration file
atlas migrate diff <migration_name> \
  --dir     "file://db/migrations" \
  --to      "file://db/schema.hcl" \
  --dev-url "docker://postgres/16/dev"

# Apply pending migrations
atlas migrate apply \
  --dir "file://db/migrations" \
  --url "$DATABASE_URL"

# Lint migrations (catch destructive changes)
atlas migrate lint \
  --dir     "file://db/migrations" \
  --dev-url "docker://postgres/16/dev" \
  --latest  1
```

## Decimal Cheatsheet

```go
import "github.com/govalues/decimal"

// Parse from string (user input / GraphQL)
amount, err := decimal.Parse(input.Amount)

// Arithmetic — immutable, returns new value
total := allocation.Add(rollover).Sub(spent)
rate  := spent.Quo(effective)

// Constants
zero := decimal.Zero

// Rounding — always before returning in GraphQL response
result := total.Round(2)

// Format for GraphQL wire (always String)
return result.String(), nil  // "175.00"

// Comparison
if amount.IsZero() { ... }
if amount.Equal(other) { ... }
if amount.Greater(decimal.Zero) { ... }
```

## Context Helpers Pattern

```go
// internal/middleware/auth.go
type contextKey string
const userIDKey contextKey = "userID"

func UserIDFromCtx(ctx context.Context) uuid.UUID {
    v, _ := ctx.Value(userIDKey).(uuid.UUID)
    return v
}

// internal/middleware/logger.go
const loggerKey contextKey = "logger"

func LoggerFromCtx(ctx context.Context) *slog.Logger {
    if l, ok := ctx.Value(loggerKey).(*slog.Logger); ok {
        return l
    }
    return slog.Default()
}
```

## Important Domain Rules (Do Not Forget)

- `Expense.amount` must equal `SUM(ExpenseSplit.amount)` — validate in service before inserting
- `Budget.date` always first-of-month — `2026-03-01` not `2026-03-15`
- `Liability.interest_rate` null = variable rate — look up `LiabilityRateHistory`
- `Asset.current_value` updated manually — always update `last_value_updated_at` at the same time
- `Liability.current_balance` updated manually — always update `last_balance_updated_at`
- `RolloverAmount` floored at zero — `max(0, previousRemaining)`
- `PlaidItem.access_token` — AES-256 encrypted at rest, never logged, never returned via API
- `NetWorthSnapshot` — append-only, immutable after creation, no `updated_at` or `deleted_at`
- Tax estimates — always show disclaimer, never call it tax advice
- SEPP — always recommend financial advisor before user starts one
- Every DB query filters `WHERE deleted_at IS NULL` — no exceptions
- Never generate UUIDs in Go — let `gen_random_uuid()` in Postgres handle it
- Never use `float64` for money — always `govalues/decimal`
- Never call `os.Getenv` in business logic — parse config once in `internal/config/config.go`
- Never import the Clerk SDK outside of `internal/middleware/auth.go`

## Seed Data Required

These tables need seed data before the app is usable:

| Table | What to seed |
|---|---|
| `tax_brackets` | IRS brackets for current + prior years, all filing statuses, with rates |
| `irs_accounts` | 401k, Roth IRA, Traditional IRA, HSA limits for current + prior years |
| `tax_form_guide` | Document type → required form mappings (1099-NEC → Schedule C, etc.) |
| `return_profiles` | High/Medium/Low Depreciation Vehicle, Standard Investment, Real Estate |
| `return_profile_schedule` | Year-by-year depreciation rates for each vehicle profile |

Seed via Atlas migrations using `INSERT` statements in a dedicated migration file.
