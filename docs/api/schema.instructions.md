# DB Schema and Query Instructions

## Atlas Schema Conventions

All schema changes go in `db/schema.hcl`. After editing, run:

```bash
make migrate-diff   # generates migration file
make migrate        # applies to local DB
make gen            # regenerates sqlc types
```

Never write migration SQL by hand. Never edit files in `db/migrations/` directly.

Every table definition follows this template:

```hcl
table "table_name" {
  schema = schema.public
  column "id"         { type = uuid         default = sql("gen_random_uuid()") }
  column "user_id"    { type = uuid }
  # ... domain columns ...
  column "created_at" { type = timestamptz  default = sql("now()") }
  column "updated_at" { type = timestamptz  default = sql("now()") }
  column "deleted_at" { type = timestamptz  null = true }

  primary_key { columns = [column.id] }
  foreign_key "fk_table_user" {
    columns     = [column.user_id]
    ref_columns = [table.users.column.id]
    on_delete   = CASCADE
  }
  index "idx_table_user_active" {
    columns = [column.user_id]
    where   = "deleted_at IS NULL"
  }
}
```

## Column Types

| Use case | Type |
|---|---|
| Money amounts | `NUMERIC(12,2)` — never FLOAT |
| Large balances (net worth) | `NUMERIC(14,2)` |
| Rates / percentages | `DECIMAL(7,4)` — e.g. 0.2200 for 22% |
| Small rates | `DECIMAL(5,4)` — e.g. 0.0350 for 3.5% |
| Primary keys | `UUID` with `DEFAULT gen_random_uuid()` |
| Timestamps | `TIMESTAMPTZ` with `DEFAULT now()` |
| Budget month | `DATE` — always first-of-month |

## on_delete Behavior

- `CASCADE` — child records deleted when parent is deleted (e.g. user → budgets → expenses)
- `SET_NULL` — child survives but loses the FK reference (e.g. expense loses its recurring source)
- `RESTRICT` — prevent deletion if child records exist (e.g. can't delete account referenced by SEPP)

## Partial Indexes — Use on Every High-Traffic Table

```hcl
index "idx_expenses_budget_active" {
  columns = [column.budget_id]
  where   = "deleted_at IS NULL"
}
```

Partial indexes only index non-deleted rows. Since almost every query filters `WHERE deleted_at IS NULL` this dramatically reduces index size and improves read performance.

## Unique Constraints

Junction tables always have a unique composite index:

```hcl
index "idx_asset_people_unique" {
  columns = [column.asset_id, column.person_id]
  unique  = true
}
```

One budget per user per month:

```hcl
index "idx_budgets_user_date" {
  columns = [column.user_id, column.date]
  unique  = true
}
```

## Check Constraints

```hcl
check "splits_amount_positive" { expr = "amount > 0" }
```

Add check constraints for any column with a logical range restriction.

## Seed Data Tables

These tables require seed data before the app is usable. Seed via a dedicated SQL file in `db/seed/`:

- `tax_brackets` — IRS brackets for current + prior years, all filing statuses, with rates

## sqlc Query Conventions

One `.sql` file per domain in `db/queries/`. Always include the sqlc annotation comment.

Query name format: `VerbNoun` — e.g. `GetBudget`, `ListCategoriesForBudget`, `CreateExpense`, `SoftDeleteExpense`.

Always filter `deleted_at IS NULL`:

```sql
-- name: ListCategoriesForBudget :many
SELECT *
FROM   expense_categories
WHERE  budget_id  = $1
  AND  deleted_at IS NULL
ORDER BY description;

-- name: SoftDeleteExpense :exec
UPDATE expenses
SET    deleted_at = now(),
       updated_at = now()
WHERE  id      = $1
  AND  user_id = $2
  AND  deleted_at IS NULL;
```

For DataLoader batch queries use `= ANY($1::uuid[])`:

```sql
-- name: GetCategorySpentAmounts :many
SELECT
  s.category_id,
  SUM(s.amount) AS total_spent
FROM  expense_splits s
WHERE s.category_id = ANY($1::uuid[])
  AND s.deleted_at  IS NULL
GROUP BY s.category_id;
```

Never write raw SQL strings in Go code. All queries live in `db/queries/*.sql` and are generated by sqlc into `internal/db/`.

## sqlc.yaml Type Overrides

The sqlc config maps Postgres types to Go types:

```yaml
overrides:
  - db_type: "uuid"
    go_type:
      import: "github.com/google/uuid"
      type:   "UUID"
  - db_type: "numeric"
    go_type:
      import: "github.com/govalues/decimal"
      type:   "Decimal"
  - db_type: "pg_catalog.numeric"
    go_type:
      import: "github.com/govalues/decimal"
      type:   "Decimal"
```

Both `numeric` and `pg_catalog.numeric` overrides are required — sqlc uses both type names depending on how the column is defined.
